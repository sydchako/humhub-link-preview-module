# Security Policy

Sytvil Link Preview performs server-side requests to third-party URLs, so security issues involving SSRF, redirect handling, URL validation, local-file exposure, cache poisoning, or request bypasses are treated as high priority.

## Supported version

Security fixes are targeted at the latest release.

## Reporting a vulnerability

Please do not open a public GitHub issue for a suspected security vulnerability. Contact the maintainer privately through the contact details on the maintainer's GitHub profile and include:

- affected version;
- reproduction steps;
- expected and actual behavior;
- any proof-of-concept request or URL;
- potential impact.

Please allow reasonable time for investigation and a fix before public disclosure.
