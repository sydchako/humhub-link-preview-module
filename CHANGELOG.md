# Changelog

## 2.0.0 — 2026-09-12

- Added configurable multiple previews per rich-text item.
- Added local image and favicon caching/proxying.
- Added favicon fallback.
- Added refresh and hide controls.
- Added admin cache dashboard and purge controls.
- Added domain allow/block/no-image rules and per-domain TTLs.
- Added per-domain request limiting.
- Added canonical URL handling and tracking-parameter cleanup.
- Added richer article metadata.
- Added provider-aware presentation for YouTube, Vimeo and GitHub.
- Added visible preview failure states and retry support.
- Added dark-theme and compact mobile styling.
- Added migration guards and retained SSRF protections.

## 1.0.0 — 2026-09-12

- Initial release.
- Automatic cached link previews for HumHub rich-text output.
- Open Graph, Twitter Card and HTML metadata extraction.
- SSRF protections and shared-hosting-friendly caching.
